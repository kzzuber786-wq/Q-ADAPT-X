# Q-ADAPT X: Autonomous Quantum Intelligence Engine (prototype)

Open `index.html` in any modern browser. No install or server needed.

Domains: quantum chemistry (VQE / ADAPT-VQE on H2), optimization (QAOA, hybrid, simulated annealing on MaxCut), quantum AI (quantum / hybrid / RBF kernels).
Flow: analyze -> generate candidates -> assess resources -> execute -> re-evaluate and adapt -> explain.

Notes: simulator only; noise is a synthetic depolarizing model and runtimes are modelled.
Next step: replace the execution layer with Qiskit + IBM Runtime backends.
